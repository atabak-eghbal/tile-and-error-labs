# Tile & Error labs

Free, hands-on GPU notebooks from the [Tile & Error Academy](https://tile-and-error-academy.vercel.app): real Triton
kernels you can open in Colab or Kaggle with one click on a free account. No GPU? Every notebook still runs its
correctness checks on Triton's CPU interpreter.

See [labs/README.md](labs/README.md) for the list, the "Open in Colab" links and how to turn on a free GPU.
Videos: [youtube.com/@tileanderror](https://www.youtube.com/@tileanderror)
